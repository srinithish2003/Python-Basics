# Python Basics – Input, Output & Basic Operations

## Overview

This folder contains four basic Python programs developed to practice fundamental concepts such as user input, variables, string operations, formatted output, and arithmetic calculations.

## Programs

### 1. Multiplication of Two Numbers

* Accepts two integer values from the user.
* Calculates and displays their product.
* Concepts: `input()`, type conversion, variables, arithmetic operators.

### 2. Print and String Operations

* Demonstrates Python `print()` statements and escape characters.
* Performs string concatenation and calculates string length.
* Concepts: Strings, `print()`, concatenation, escape characters, `len()`, user input.

### 3. User Details

* Accepts the user's name and city.
* Displays the details using a formatted message.
* Concepts: `input()`, variables, f-strings, string formatting.

### 4. Area of a Sphere

* Accepts the radius of a sphere.
* Calculates and displays its surface area using the formula `4 × π × r²`.
* Concepts: User input, variables, arithmetic operations, mathematical formulas, f-strings.


## Execution

Each program can be executed independently using:

python filename.py
