# Day 4 – Python For Loops and Password Generator

## Overview

This folder contains my Day 4 Python practice programs focused on **`for` loops and iteration**. The exercises involve iterating through lists, working with the `range()` function, performing calculations, and solving common programming problems using loops.

The folder also includes a **Password Generator challenge**, which combines loops, lists, randomisation, and string manipulation to generate a customized password.

## Programs

### 1. Fruit Pie Generator (loops.py)

Iterates through a list of fruits using a `for` loop and appends the word `"Pie"` to each fruit before displaying it.

### 2. Sum of Numbers Using `range()` (range_func.py) 

Uses a `for` loop and the `range()` function to iterate through a sequence of numbers and calculate their total.

### 3. Sum of Even Numbers

Accepts a target number from the user and calculates the sum of all even numbers up to that value using `range()` with a step value of `2`.

### 4. FizzBuzz

Loops through numbers from 1 to 100 and applies conditional statements to print:

* `Fizz` for numbers divisible by 3
* `Buzz` for numbers divisible by 5
* `FizzBuzz` for numbers divisible by both 3 and 5
* The number itself for all other values

### 5. Highest Student Score

Accepts a list of student scores and uses a `for` loop to identify the highest score without using Python's built-in `max()` function.

### 6. Average Student Height (height.py)

Accepts a list of student heights and calculates the total height, number of students, and average height. This exercise demonstrates how the functionality of built-in functions such as `sum()` and `len()` can be replicated using `for` loops.

### 7. PyPassword Generator 

An interactive password generator that allows the user to specify the number of letters, symbols, and numbers required in the password.

Random characters are selected using the `random` module, stored in a list, shuffled to avoid a predictable order, and finally combined into a single password string.

## Concepts Covered

* `for` loops
* Iterating through lists
* `range()` function
* Conditional statements
* Arithmetic operations
* Finding maximum values using loops
* Calculating sums and averages
* Replicating basic built-in functions using loops
* Lists and list operations
* Python `random` module
* `random.choice()` and `random.shuffle()`
* `append()` method
* String manipulation and `"".join()`
* Basic problem-solving using Python

## Learning Outcome

Through these exercises, I practiced using `for` loops to process collections of data, perform repeated calculations, and solve basic programming challenges. The Password Generator challenge also helped combine multiple Python concepts into a single interactive program.
