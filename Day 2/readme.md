# Python Basics – Conditional Statements

## Overview

This folder contains Python programs focused on conditional statements and decision-making using `if`, `elif`, `else`, logical operators, nested conditions, and basic calculations.

## Programs

### 1. Even or Odd Number

* Accepts a number and checks whether it is even or odd.
* Concepts: `if-else`, user input, modulo operator.

### 2. Age Category

* Accepts the user's age and categorizes it as Minor, Adult, or Senior Citizen.
* Concepts: `if-elif-else`, comparison operators, logical operators.

### 3. Leap Year

* Determines whether a given year is a leap year.
* Implements both nested conditions and a simplified logical-condition approach.
* Concepts: Nested `if`, logical operators, comparison operators.

### 4. Python Pizza Delivery

* Calculates the final pizza bill based on pizza size, pepperoni, and extra cheese selections.
* Concepts: `if-elif-else`, nested conditions, string methods, arithmetic operations, user input.

### 5. BMI Calculator

* Accepts height and weight from the user and calculates the Body Mass Index (BMI).
* Categorizes the result based on the calculated BMI value.
* Concepts: Type conversion, arithmetic operations, `if-elif-else`, comparison operators, formatted output.

## Concepts Covered

* `if`, `elif`, `else`
* Nested conditional statements
* Comparison operators
* Logical operators (`and`, `or`)
* Modulo operator (`%`)
* String methods
* User input and type conversion
* Basic calculations
* Formatted output
